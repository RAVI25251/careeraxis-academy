# CareerAxis Academy v3.3 — Authentication Stability Fix

## Fixed
- Prevented repeated `onAuthStateChange` subscriptions during admin rendering.
- Prevented the auth listener from calling `render()` recursively.
- Added a single initialization promise so the admin auth client is initialized once per page lifecycle.
- Google OAuth now returns to the same browser origin that started sign-in, which is safer for local testing and production.
- Sign-out clears the local OTP verification marker.

## Important
The Google OAuth client still needs the appropriate authorized origin/redirect configuration for whichever environment is being tested. The production domain is already configured; localhost requires adding the local site URL to the Supabase Auth redirect allow-list and Google OAuth JavaScript origins if local Google sign-in is desired.

## Security
- The browser contains only the Supabase publishable key.
- Never put a Supabase secret/service-role key, Google OAuth client secret, or Google Drive refresh token in frontend files.
